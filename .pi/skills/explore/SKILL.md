# Explore（探索 / 启发）

`teach` 回答的是「教我 X」——已经进入「我知道我不知道」。`explore` 回答的是**还没被问出来的问题**：基于已经学过的全部内容，主动启发接下来学什么。这是四象限里另外两格的来源。

## 输入（先读）

1. `knowledge/_map.md`——全局知识地图（领域 → 主题 → 知识点 + 四象限状态）。
2. `.pi/learner/profile.md`——学习者档案（讲法偏好、已知误解、最近会话）。
3. `knowledge/` 目录树——必要时 `ls` / 抽读几篇笔记，确认地图是否落后于现实。
4. `resources/`——手头已有哪些材料（`sources.md` / `wanted.md`）。

## 四象限

| 象限 | 含义 | 怎么得到建议 |
|---|---|---|
| ✅ **知道自己知道** | 会，且知道 | 地图上已确认的节点 → 建议**进阶/深化**（同主题更深的点，或它依赖链的上游） |
| 🎯 **知道自己不知道** | 不会，且知道 | 地图上标为缺口/天花板的点 → **直接可学的下一节**，最省事、最该先做 |
| 💤 **不知道自己知道** | 会，但没意识到 | 用过但从没"点名"过的点（凭直觉答对、反复用却从未被正式确认）→ 建议一次**快速 probe**把它正式化 |
| 🕳 **不知道自己不知道** | 不知道，且不知道 | 地图的**相邻盲区**：该领域的人普遍会、但地图上完全没有的点 → **主动提出** |

## 流程

1. **读上面四份输入。** 如果地图为空或很薄，先坦白——告诉他现在素材不够做探索，建议先学几个点再回来。
2. **算相邻盲区（最需要主动性的一格）。** 对地图上每个已学主题，派 `researcher` 问：*"一个掌握了这个主题的人，通常还会知道哪些邻近的概念？"* 再和地图比对，差集就是盲区候选。
3. **产出 3-6 条建议**，每条给：**一句话内容 + 为什么现在值得学（挂在哪个已有节点上）+ 属于哪个象限**。宁少勿多。缺口优先（他知道缺、最容易推进），盲区其次（最有启发性），未点名与进阶作为补充。
4. **让他挑**：用 `ask_user_question` 把建议作为选项（最推荐的一条放第一并标 `(Recommended)`）。也允许"都不是 / 我想学别的"。
5. **交接**：他选定后，**切到 `teach` 流程**——按 `teach` 的 Phase 1 先 probe 他在该主题的边缘，再 plan → teach。**不要在这里直接开讲。**

## 原则

- **建议要具体到一个知识点**，不要给"建议深入学 Flink"这种空话。
- **每条建议都要有"为什么现在"**：它挂在哪个已学节点上、补哪条依赖边。
- **不要为了凑数编造方向。** 地图薄就说地图薄。
- **盲区不是恐吓**：语气是"你可能没意识到这个也相关，要不要看看"，不是"你居然不知道这个"。
- 探索本身也是一次 probe：他对某些建议"哦这个我知道"——那就是**不知道自己知道**的现成信号，顺手记进地图/档案。

## 输出

结尾给一段简短小结：这次覆盖了哪几格、他选了什么、下一步。若他没选，把候选方向作为 `🎯 缺口` 追加进 `knowledge/_map.md`，供以后再用。
